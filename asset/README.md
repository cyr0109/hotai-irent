# asset/

前端原型（`取車拍照.html`，之後還有還車端）用到的素材。

**檔名一律使用 ASCII、小寫、連字號。** 中文加空白的檔名在 GitHub、CI、跨 OS 工具鏈上需要 URL encode，是不必要的地雷。原始資料夾（`沒有進行索賠/`、`進行索賠資料/`）保持原樣不動，`asset/` 放的是整理後供前端使用的副本。

### 取車 Demo 情境

`取車拍照.html` 目前提供多種四角拍照判定情境：

| 情境            | 說明                                      |
| ------------- | --------------------------------------- |
| 全部通過          | 四個方向皆正確，車牌正常                            |
| 缺左後角度         | 其中一張實際拍成右後，模擬方向拍錯                       |
| 僅無完整車牌        | 四角方向正常，但模擬車牌辨識不完整                       |
| **方向拍錯但車牌正常** | **新增情境：方向有誤，但車牌辨識正常，用來測試方向判定與車牌判定分開處理** |

判定目前仍以 demo mock 情境為主，並非真正接上影像辨識模型。

## 取車流程目前狀態

目前 `取車拍照.html` 已完成主要拍照流程與 Demo 判定情境：

1. 檢查車輛
2. 車況預先回報
3. 進入四角拍照
4. 四角照片判定
5. 車損照片拍攝
6. 完成／略過車損照片
7. C3 補拍提示
8. 免責聲明
9. 確認取車
10. 用車說明／用車頁

四角判定 Demo 目前除了原本的「全部通過」、「方向拍錯」、「車牌異常」外，新增：

> **方向拍錯但車牌正常**

用來驗證「照片方向判定」與「車牌完整性判定」可以作為不同條件處理。

## 上傳到 GitHub 前

這些照片部分來自**和泰／iRent 提供的解題資料**，不是我們自行製作的公開素材。公開 repo 等於對外散布，且照片可能包含實際車輛與車牌。

建議：

* 先確認主辦方對解題資料的使用範圍
* 若不確定，使用 private repo
* 若需要公開 repo，可以考慮將 `asset/` 加入 `.gitignore`
* 對外公開前確認照片中的車牌與其他可識別資訊是否可以公開

程式碼與規格文件可以獨立公開，素材則依主辦方授權範圍處理。
