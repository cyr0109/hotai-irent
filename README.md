# AI 打造 iRent 智能車況管家

2026 和泰 AI 黑客松 · 團隊「喔喔喔 AI 什麼是 AI」
題目：運用 AI 打造 iRent 智能車況管家，優化租還車體驗與營運效率

👉 **[立即試玩前端 Prototype](https://cyr0109.github.io/hotai-irent/home/)**（手機或電腦都能開）

## 痛點

| 用戶 | 後台及營運人員 |
|---|---|
| 不確定拍的照片品質是否合格 | 要花大量人力即時查看照片 |
| 不知道上一位用戶用完後的車況 | 難以第一時間攔截車損、髒亂 |
| 照片只存在 iRent 資料庫，用戶手機沒有留存，責任歸屬不透明 | 爭議時照片證據不完整，難以釐清責任 |
| 承接上一手的髒亂車輛，體驗不好 | |

## 解決方案

三個重點：
1. **拍照時的虛線引導＋AI 防呆**，提升取還車的安心感。
2. **傳統 CV 模型＋AI Agent** 自動判斷車況是否異常，減少人工審核成本。
3. **AI Agent 統整辨識結果與緊急程度**，加速車輛維護的營運決策。

| 角色 | 做什麼 |
|---|---|
| iRent 用戶 | 拍照有虛線引導、AI 判斷各角度是否拍齊；取車前可看上一位用戶的還車車況；照片同步留存在手機；誠實回報、保持整潔可得和泰 Points |
| AI Agent | 判定有無新車損與髒污；異常即時通知後台；整理當次租期的照片與判定成報表；依緊急程度排派工順序 |
| 後台人員 | 依 AI 報表人工審核、決定是否求償；依排序派工清潔或維修 |

**流程**：取車先看上一位的車況，有問題可拍照回報，再簽責任歸屬同意書，經引導與防呆拍照上傳。還車同樣流程，拍完由 AI Agent 比對，有新車損或嚴重髒污就通知求償並更新結果頁。

## AI 怎麼做

**手機端 AI 防呆**（即時，輕量模型）

| 檢查 | 做法 |
|---|---|
| 車牌偵測 | YOLO 找車牌，檢查是否完整入鏡 |
| 拍攝角度 | MobileNetV3-small，用官方提供的資料集訓練四分類：左前、右前、左後、右後，拍完比對「要求的角度」 |
| 車佔比 | YOLO 框車身，算佔畫面比例，太遠或太近就提示 |
| 亮度、模糊 | 傳統 CV，亮度不足時提示開閃光燈 |

這些都是軟提示：用戶可以略過直接送出，但要簽責任歸屬同意書。

**後端車損與髒污辨識**（兩層）

1. **傳統 CV**：ORB 特徵比對確認取還車角度相同，再各自跑 YOLO 車損模型，取車沒有、還車有就判定為新車損。
2. **AI Agent**：取還車角度對不上、或 CV 信心度不夠時，交給和泰自架機房的 **Hotai GPT**（基於 Qwen3-VL fine-tune）同時看取車與還車照片，判斷是新車損、舊傷、髒污或需人工審查。

輸出：有沒有新車損、位置、類型、髒污與否，以及判斷依據。車內整潔度分為髒污／普通／乾淨三類。

**後台預警**：AI Agent 調閱租還車紀錄、時間序、GPS，產出報告並規劃維修排序，後台人員可再自行審核。

更多細節：[docs/AI技術架構.md](docs/AI技術架構.md)

## 與 iRent 現況的差異

| 面向 | 現況 | 我們 |
|---|---|---|
| 查看上一位車況 | 無 | 取車前可看上一次租借照片 |
| 影像品質、亮度 | 無引導 | 光線不足、距離遠近都有提醒 |
| 車牌與角度 | 無引導 | 虛線引導、車牌完整性檢查 |
| 誠實回報 | 無獎勵 | 和泰 Points 回饋 |
| 照片留存 | 只在 iRent 資料庫 | 自動留存在用戶手機 |
| 新車損 | 人工判斷 | AI 比對、即時預警 |
| 髒污 | 整備人員巡邏 | AI 分三級、異常預警 |
| 異常通知 | 缺少即時通知 | 自動通報後台 |

## 預期效益

- **用戶**：源頭確保照片合格；良好用車習慣換點數，形成正向循環。
- **後台**：AI 先過濾、標註異常，不用手動翻照片；客訴時可一次調閱時間序、GPS 與判定結果。
- **營運**：從被動等待變成即時預警，避免問題車輛再被租出；車損與髒污分級，加速整備、提升周轉率。
- **企業**：減少責任不清造成的客訴與賠償；累積車況影像與軌跡，為智慧調度與預防性維護打底。

## 落地評估

| 階段 | 內容 |
|---|---|
| 第 1–3 個月 MVP 驗證 | 拍照流程、即時品質檢測、車況預先回報、補拍與免責聲明 |
| 第 4–7 個月 AI 車況辨識 | 車牌、方位、車損辨識、車內髒污分類 |
| 第 8–12 個月 客服營運整合 | 後台異常預警、車況紀錄頁、清潔整備通知 |
| 第 12 個月起 智慧管理 | 資料累積、點數優化、長期分析與預測性維護 |

架構：App 端整合現有 iRent App，內嵌拍照 SDK 做即時品質檢測；後端擴充和泰車況資料庫，建立車況影像證據鏈。模型部署分兩路，行動端用開源輕量模型，內部機房用 Hotai GPT。
