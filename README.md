# iRent 智能車況管家

2026 和泰 AI 黑客松：用 AI 優化 iRent 共享汽車的租還車體驗與營運效率。

## 👉 [立即試玩 Demo](https://cyr0109.github.io/hotai-irent/home/)

手機或電腦都能開。取車、還車兩條動線可以一路跑到底。
手機開會真的用到相機與陀螺儀（iOS 會問權限）。

## 解決什麼問題

租還車時的照片常常不堪用：模糊、角度沒拍全、車牌沒入鏡。事後有車損糾紛，就沒有證據。

我們在**拍照當下**就用 AI 把關，還車時再自動比對新車損、判斷車內整潔度，異常交給後台人工複核。

## 原型現況

**取車（P1–P10，完整）**：靠卡設定 → 檢查車輛四周 → 車況預先回報 → 拍照序列（四角必拍＋車損 optional）→ 拍後檢查／補拍／免責聲明 → 確認取車 → 用車說明 → 用車頁。四條路徑都走得通——回報沒問題／回報有問題後繼續租車／回報有問題後放棄租車／任一路徑遇到照片缺項。

**還車（R1–R12，完整）**：檢查清單 → 地點類型（路邊／停車場兩條分支）→ 檢查車輛狀況 → 車況預先回報 → 十一格拍照序列 → 拍後檢查／補拍／免責聲明 → 內裝髒污攔截（整理重拍或仍要還車）→ 提供停車位置（真的會進相機）→ 鎖車 → 背景比對 → 推播 → 車況紀錄頁。

**兩條動線相連**：取車跑到底的「用車頁」按「開始還車」會跳到還車原型；控制面板頂端也有取車／還車切換。

**待做**：後台 dashboard（環節三，另開文件）、素材補齊（見 `asset/README.md`）、接上真實模型（角度覆蓋與車牌完整性目前是 mock）。

**真的在運算的**：手機姿勢硬擋（陀螺儀）、模糊偵測（Laplacian 變異數）、低光偵測（平均亮度）。
**還是 mock 的**：角度覆蓋、車牌完整性——等模型。接縫收在 `fetchJudgement()` 一支函式，回傳格式就是未來的 API 契約，接真模型時只換函式內容。

## 本機執行

```bash
python3 -m http.server 8000
open http://localhost:8000/
```

必須用 server，不能直接 `file://` 開——素材路徑與 iOS 陀螺儀權限都要求 http(s)。
